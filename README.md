# 우마워들 (142명)

정적 HTML 사이트입니다. `index.html`을 더블클릭하거나 GitHub Pages / Netlify에 폴더 전체를 올리면 됩니다.

## 기능
- 시작 전에 제한 횟수 N 설정
- 142명 중 정답 1명 랜덤 선정
- 이름 검색 / 스크롤 목록 선택
- G1 승수, 출생년도, 신장, B/W/H, 적성 비교
- 일치 / 비슷함 / 다름 + 정답 방향 ↑↓
- 성공/실패 시 정답 상세 공개
- 데이터 관리 탭에서 전체 필드 수정, 이미지 업로드/경로 지정
- JSON 내보내기 / 불러오기 / 기본값 복원

## 비교 기준 (현재 기본값)
- G1 승수: 차이 1 이내 = 비슷함
- 출생년도: 차이 2년 이내 = 비슷함
- 신장: 차이 3cm 이내 = 비슷함
- B/W/H: 각 수치 차이 3cm 이내 = 비슷함
- 적성: A~G에서 한 단계 차이 = 비슷함

데이터 관리에서 저장한 내용은 브라우저 localStorage에 저장됩니다.
